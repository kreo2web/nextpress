The assistant helps you write and change pages and docs. You describe what you want, and it changes the page in the editor. It works on the copy of the page that is open, and it uses the same checks as the editor.

## Who can use it

Editors, admins and owners can use the assistant. Subscribers cannot. Every request uses the site's AI key. Set that key up first, as described in [Set up AI](/docs/ai-assistant/set-up-ai).

## Build a page

When you create a page, you can write a short description. Describe the page you want, such as "a landing page for a yoga studio with a booking button, class times and a contact form". When the assistant is set up, it builds the page from that description as the editor opens.

You can also ask for changes in the **Assistant** tab of the page builder. Each page keeps its own conversation. The tab shows the live steps while the assistant works.

## What the assistant checks

The assistant works within the same checks as the editor. A change that would break the page, such as a block the server would refuse to save, is not saved. The assistant tells you what to fix instead.

The assistant follows the same design guide that the MCP server uses, so the pages it builds follow the same rules.

## Work on docs

In the docs editor, the assistant writes and edits MDX. That is the same text the docs page is saved as. See [Writing docs](/docs/pages-and-content/writing-docs).

## Change one block

Select a block, then choose **Ask AI** to ask the assistant about that block only.

## Undo a change

Each page keeps its earlier versions. If you do not like a change, you can put an earlier version back.

<Callout type="tip" title="Check before you publish">

Preview the page and check it on each screen size before you publish it.
