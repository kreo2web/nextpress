Each person has a role on each site. The role decides what they can do on that site. Roles are kept per site, so one person can have different roles on different sites.

## The roles

| Role | What they can do |
|---|---|
| Subscriber | Comment and keep a profile. Subscribers have no dashboard |
| Editor | Write and edit pages, posts and media, answer comments, and use the AI assistant |
| Admin | Everything an editor does, plus the site's settings, theme, API keys and people |
| Owner | The site's owner. An owner can do everything an admin can |

Editors, admins and owners use the dashboard for their site. Subscribers do not.

## What each permission covers

Each role can do some of these actions on a site:

- **Edit content:** pages, posts, blogs, media, blocks, linked parts, forms and their answers, imports and previews.
- **Moderate comments:** approve, mark as spam, change or delete comments. Editors, admins and owners can do this.
- **Use the assistant:** use the page assistant, which spends the site's AI key. Editors, admins and owners can do this.
- **Manage the site:** change the site's settings, address, theme, options, API keys and AI settings. Admins and owners can do this.
- **Manage people:** decide who has which role on the site, and create invite links. Admins and owners can do this.

## Invite people

Admins manage people from the **People** screen. There they choose each person's role on the site, and they can create invite links for new people.

## Main site admins

The owner or an admin of the main site has extra reach. They can manage all users, plugins, sites and updates, on every site in the install.

<Callout type="note" title="Updates are for the main site only">

Only the main site's owner or admins see the **Update available** notice and can start an update from the dashboard. See [Upgrade](/docs/getting-started/upgrade).

</Callout>
