The page builder is where you design pages. You add blocks to the canvas, style them, and check each one on desktop, tablet and mobile. Preview and the live site use the same renderer, so what you see in preview is what visitors get after you publish.

## Blocks

A page is made of blocks. Headings, text, images, buttons, columns, grids and forms are all blocks. Blocks can hold other blocks. For example, a columns block can hold text and pictures in each column.

Drag a block from the **Blocks** panel onto the canvas. The panel groups the blocks into sections such as Basic, Layout, Media, Form and Post. Post blocks show blog content on a page. Docs blocks are used only in the [docs editor](/docs/pages-and-content/writing-docs).

## Block settings

Select a block on the canvas to change it. Its settings are split into three tabs:

- **Content** holds what the block shows, such as its text, pictures and link addresses.
- **Style** holds how it looks, such as spacing, colors and hover states.
- **Advanced** holds the less common options.

The icon picker lets you browse four icon sets before you search. Use it to add an icon to a block.

## Device preview

Switch the canvas between **Desktop**, **Tablet** and **Mobile** to see the page at each width. Check each size before you publish, because a layout that works on a wide screen may need adjusting on a phone.

## Save, preview and publish

<Steps>

<Step title="Changes save as you work">

The editor saves your changes automatically. Use undo and redo in the top bar to step back and forward through your changes.

</Step>

<Step title="Preview the page">

Press **Preview** to see the page as it will look live. You can also create a preview link. Anyone with the link can open the preview without signing in.

</Step>

<Step title="Publish">

Press **Publish** to make the page live at its address.

</Step>

</Steps>

<Callout type="tip" title="Undo a mistake">

Press `Ctrl` + `Z` to undo. On a Mac, press `⌘` + `Z`.

</Callout>

## Page settings

Open **Page settings** to change the page's title, web address, status, template, fonts, width and padding. You also set the search and sharing text, which are the page's meta title and description. Parent and menu order are here too.

A page placed under another page gets an address that starts with its parent's address. For example, a docs page under a Getting started group gets `/docs/getting-started/install`.
