A page file carries one page so you can move it to another site. You export the file from one site, then import it into the other. Use this to move a page, or a whole docs, between sites.

## Export a page

<Steps>

<Step title="Open the Pages screen">

Find the page in the list. Open its menu and choose **Export**.

</Step>

<Step title="Choose what goes in the file">

Switch on **Include images, videos and other files** to bring the page's media along. Leave it off to make a small file with no images or videos.

Pages that the page links to are listed too. Pick the ones to bring along.

</Step>

<Step title="Save the file">

Save the file. It is a page file, and you import it into the other site next.

</Step>

</Steps>

## Import a page

<Steps>

<Step title="Open the Pages screen on the other site">

Switch to the site you want to bring the page into. Press **Import page**.

</Step>

<Step title="Choose the file">

Choose the page file you exported. The page comes in as a draft.

</Step>

</Steps>

If the page's address is already used on the other site, the imported page gets a new address. Links to the page follow the new address.

<Callout type="note" title="Check the imported page">

Open the imported page in the page builder, check it on each screen size, and publish it when it is ready.

</Callout>

## Move a docs

Export a whole docs in one step. On the **Docs** screen, press **Export docs** on the docs card. The file holds every page of the docs with its tree, so the sidebar order comes along too.

Import that file with **Import page** on the Pages screen of the other site, the same way as a single page. See [Writing docs](/docs/pages-and-content/writing-docs).

<Callout type="tip" title="Large files">

A page file with images and videos can be tens of megabytes. Export without files when you only need the text.

</Callout>
