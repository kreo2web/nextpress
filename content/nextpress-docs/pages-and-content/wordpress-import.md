NextPress can bring posts and pages over from an existing WordPress site. The import reads the published content from the site's public address, and it turns WordPress blocks into NextPress blocks.

## What the import does

- Imports published posts and pages from a public WordPress address.
- Converts the Gutenberg HTML and layout blocks into native NextPress blocks.
- Refreshes content you already brought over when you import it again.

## Import from WordPress

<Steps>

<Step title="Open the import">

Open **Tools**, then **Import WordPress**.

</Step>

<Step title="Enter the WordPress address">

Enter the address of the WordPress site. The site must be public, because the import reads its published posts and pages.

</Step>

<Step title="Import the content">

Import the posts and pages you want. Then check them in the admin before you publish them.

</Step>

</Steps>

<Callout type="note" title="Import again to refresh">

Running the import again updates content you have already brought over. Check the content after each import.

</Callout>
